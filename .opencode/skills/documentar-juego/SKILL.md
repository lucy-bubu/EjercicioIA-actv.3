# Documentación de app.js

## Procedimiento
1. Lee `AGENTS.md` y `app.js`.
2. Identifica las funciones y las variables de estado.
3. Propón comentarios JSDoc solo para funciones cuyo propósito, parámetros o retorno no sean evidentes.
4. Explica el flujo del juego con vocabulario de 2.º DAW.
5. No cambies nombres, preguntas, respuestas, HTML, CSS ni comportamiento.

## Salida obligatoria
- Lista de elementos a documentar y justificación.
- Propuesta de comentarios JSDoc en bloques de código.
- Explicación breve del flujo de ejecución.
- Lista de comprobaciones posteriores para confirmar que la documentación no cambió el comportamiento.
